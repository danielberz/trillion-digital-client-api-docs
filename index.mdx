<Note>
Two APIs, and most integrations use both. The **Trading API** covers the moment
of the trade — prices, quotes, orders, fills. The **Platform API** covers
everything around it — settlement instructions, whitelisting, transfers, and
reporting. If you are not sure which you need, start at
[Which API do I need?](/choosing-an-api).
</Note>

## Choosing an integration path

<Steps>
  <Step title="Trade programmatically">
    Use the [Trading API](/trading-api/overview). Market data, RFQ, and order
    execution run over a persistent WebSocket connection; historical and
    reference data are available over REST. FIX 4.4 is supported for
    institutional order flow.
  </Step>
  <Step title="Trade manually">
    Use the web terminal. Your account manager will provision access during
    onboarding — see [Getting started](/guides/getting-started).
  </Step>
  <Step title="Reconcile and report">
    Trade, balance, and settlement history are available over the Trading API
    today, and over the [Platform API](/platform-api/overview) once released.
  </Step>
</Steps>

## Getting credentials

API keys are issued per environment — sandbox and production keys are separate
and not interchangeable. Email
[support@trilliondigital.io](mailto:support@trilliondigital.io) to request them.

<Note>
Sandbox is a full-featured test environment with simulated liquidity. Always
build and certify against sandbox before requesting production credentials.
</Note>
