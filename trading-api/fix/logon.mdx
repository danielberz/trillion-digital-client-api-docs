---
title: "FIX logon"
description: "Authenticating a FIX session with an HMAC-SHA256 signature."
---

FIX sessions authenticate once, at logon, rather than per message. The signature
is carried in the Logon (`35=A`) message itself.

## Fields

<ParamField body="Password (554)" type="string" required>
  Your API key.
</ParamField>

<ParamField body="RawData (96)" type="string" required>
  The HMAC-SHA256 signature.
</ParamField>

<ParamField body="RawDataLength (95)" type="int" required>
  Length of the signature in `RawData`.
</ParamField>

## String to sign

Concatenate four values from the Logon message, separated by the **ASCII 01**
character (``, the FIX field delimiter):

```
{SendingTime(52)}{MsgSeqNum(34)}{SenderCompID(49)}{TargetCompID(56)}
```

Sign with HMAC-SHA256 keyed on your API secret, then encode as **URL-safe
base64**.

<Warning>
The separator is the SOH control character, not a literal backslash-u sequence and
not a pipe. Writing `"\\u0001"` into the string rather than the actual byte is the
single most common FIX logon failure.

Note also that this construction differs from REST and WebSocket signing, which
join with newlines over a different set of values. The two are not interchangeable.
</Warning>

## Reference implementation

```java QuickFIX/J
private static void signLogon(
        final Message message,
        final SessionID sessionId,
        final String apiKey,
        final String apiSecret) throws FieldNotFound {

    final var senderCompId = sessionId.getSenderCompID();
    final var targetCompId = sessionId.getTargetCompID();
    final var sendingTime = message.getString(SendingTime.FIELD);
    final var seqNum = message.getInt(MsgSeqNum.FIELD);
    final var sep = "";

    final var hmac = sign(
        apiSecret,
        sendingTime + sep + seqNum + sep + senderCompId + sep + targetCompId);

    message.setString(Password.FIELD, apiKey);
    message.setInt(RawDataLength.FIELD, hmac.length());
    message.setString(RawData.FIELD, hmac);
}

private static String sign(final String apiSecret, final String data) {
    final var mac = HmacUtils.getInitializedMac(
        HmacAlgorithms.HMAC_SHA_256, apiSecret.getBytes());
    final var encodedBytes = mac.doFinal(data.getBytes());
    final var encoder = Base64.getUrlEncoder(); // URL-safe
    return encoder.encodeToString(encodedBytes);
}
```

## Example Logon message

`^A` denotes the ASCII 01 delimiter.

```
8=FIX.4.4^A9=143^A35=A^A34=1^A49=CUSTOMER^A52=20220915-18:29:58.756^A56=Trillion Digital^A95=44^A96=ZduZiNxyxS7_4UPDesOryd9KVEecg9LAqqTRR79Pp20=^A98=0^A108=300000^A141=Y^A554=Daniel^A10=248^A
```

| Tag | Field | Value |
| --- | --- | --- |
| `35` | MsgType | `A` — Logon |
| `34` | MsgSeqNum | `1` |
| `49` | SenderCompID | Your assigned ID |
| `52` | SendingTime | `20220915-18:29:58.756` |
| `56` | TargetCompID | `Trillion Digital` |
| `95` | RawDataLength | `44` |
| `96` | RawData | The signature |
| `98` | EncryptMethod | `0` — none, TLS handles transport security |
| `108` | HeartBtInt | `300000` |
| `141` | ResetSeqNumFlag | `Y` |
| `554` | Password | Your API key |

<Note>
`SendingTime` must be the exact string used when computing the signature. Format
it once and reuse the value in both places.
</Note>
