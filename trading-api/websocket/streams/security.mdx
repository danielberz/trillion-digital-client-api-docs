---
title: "Security"
description: "Securities available to trade, with their increments and size limits."
---

Streams the securities available to your account. Subscribe to this first — it
tells you what symbols exist and, critically, the increments your orders must
respect.

## Subscribe

```json
{
  "reqid": 1,
  "type": "subscribe",
  "streams": [{ "name": "Security" }]
}
```

### Parameters

<ParamField body="Symbols" type="string[]">
  Optional list of symbols to filter on. Omit for all securities.
</ParamField>

## Response

<ResponseField name="Timestamp" type="datetime" required>Timestamp of message publication.</ResponseField>
<ResponseField name="UpdateAction" type="string" required>
  `Update`, or `Remove` when the security is no longer available.
</ResponseField>
<ResponseField name="SecurityID" type="string" required>System ID, informational only.</ResponseField>
<ResponseField name="Symbol" type="string" required>Symbol for the security.</ResponseField>
<ResponseField name="DisplaySymbol" type="string" required>Display symbol.</ResponseField>
<ResponseField name="Description" type="string" required>Description of the security.</ResponseField>

<ResponseField name="MinPriceIncrement" type="decimal" required>
  Minimum price increment.
</ResponseField>
<ResponseField name="MinSizeIncrement" type="decimal" required>
  Minimum size increment. Validates orders and RFQs expressed in the security's
  **base** currency.
</ResponseField>
<ResponseField name="MinAmtIncrement" type="decimal">
  Minimum amount increment. Validates orders and RFQs expressed in the **quote**
  currency.
</ResponseField>
<ResponseField name="DefaultPriceIncrement" type="decimal" required>
  Default price increment used in market data and orders.
</ResponseField>
<ResponseField name="DefaultSizeIncrement" type="decimal" required>
  Default size increment used in market data and orders.
</ResponseField>

<ResponseField name="MinimumSize" type="decimal" required>Minimum order size.</ResponseField>
<ResponseField name="MaximumSize" type="decimal">Maximum order size.</ResponseField>
<ResponseField name="NormalSize" type="decimal">Normal size of the security.</ResponseField>

<ResponseField name="BaseCurrency" type="string" required>Base currency.</ResponseField>
<ResponseField name="QuoteCurrency" type="string" required>Currency the security is quoted in.</ResponseField>
<ResponseField name="PositionCurrency" type="string" required>Currency positions are tracked in.</ResponseField>
<ResponseField name="SettlementCurrency" type="string">Currency settlement is negotiated in.</ResponseField>

<ResponseField name="PriceDisplaySpec" type="string" required>
  Specification describing how to display prices.
</ResponseField>
<ResponseField name="SizeBuckets" type="decimal[]" required>
  Default size buckets for `MarketDataSnapshot` streams.
</ResponseField>
<ResponseField name="ProductType" type="string">Product type.</ResponseField>
<ResponseField name="NotionalMultiplier" type="decimal">Notional multiplier.</ResponseField>
<ResponseField name="Expiration" type="decimal">Expiration of the security.</ResponseField>
<ResponseField name="EndTime" type="datetime">Date this security was disabled.</ResponseField>
<ResponseField name="Rank" type="integer">Security rank.</ResponseField>

<Warning>
Increments are the most common cause of rejected orders. A quantity or price that
is not a whole multiple of the relevant increment will be rejected. Note that
**which** increment applies depends on the currency you express the order in:
`MinSizeIncrement` for base-currency orders, `MinAmtIncrement` for quote-currency
orders. Round before submitting rather than reacting to a rejection.
</Warning>
